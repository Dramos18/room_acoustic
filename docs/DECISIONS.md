# DECISIONS

## DEC-001 — GitHub como fuente central
**Estado:** APROBADA  
Se mantiene el repositorio actual como punto central de código y documentación técnica.

## DEC-002 — No crear segundo repositorio
**Estado:** APROBADA  
No se duplicará el proyecto en otro repositorio.

## DEC-003 — Roles de IA
**Estado:** APROBADA  
Desarrollador: software, arquitectura, UI, modelo, pruebas y evolución técnica.  
Documentación: teoría, bibliografía, metodología, resultados y redacción.

## DEC-004 — Word como documento académico oficial
**Estado:** APROBADA  
Los MD coordinan y documentan; no sustituyen el Word.

## DEC-005 — No refactorización masiva inicial
**Estado:** APROBADA  
Primero auditoría, luego propuesta y aprobación.

## DEC-006 — Modelo acústico protegido
**Estado:** APROBADA  
Sabine, Eyring y %ALCons requieren validación antes de cambios.

## DEC-007 — Datos actuales se conservan
**Estado:** APROBADA  
Excel/diccionarios no se eliminan hasta auditar dependencias.

## DEC-008 — Lógica reutilizable
**Estado:** APROBADA  
La lógica acústica debe poder evolucionar hacia reutilización futura, incluida una posible app móvil.

## DEC-009 — Capturas versionadas
**Estado:** APROBADA  
Cambios de UI implican revisión de capturas académicas.

## DEC-010 — IA con trazabilidad
**Estado:** APROBADA  
Cambios relevantes deben quedar documentados y asociados a commits.
