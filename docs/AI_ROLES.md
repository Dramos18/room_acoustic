# AI Roles

## Claude — ingeniería de software

Responsabilidades principales: - inspección del código; -
arquitectura; - refactorización controlada; - implementación de
funcionalidades; - UI/UX técnica; - pruebas; - debugging; -
documentación técnica; - trazabilidad de cambios; - revisión de
dependencias; - preparación para futuras migraciones.

Claude debe trabajar sobre el repositorio real y no sobre una versión
imaginada del proyecto.

## Usuario desarrollador

Responsabilidades: - definir la intención funcional; - aprobar cambios
de arquitectura o modelo; - ejecutar/validar comportamiento visual
cuando corresponda; - revisar cambios relevantes; - decidir cuándo hacer
push/merge; - validar que los resultados académicos siguen siendo
correctos.

## Compañero — documentación/teoría

Responsabilidades: - tesis; - antecedentes; - metodología; -
resultados; - bibliografía; - interpretación académica; - actualización
de capturas y evidencia.

## Regla de coordinación

Cuando una tarea afecta software y tesis:

1.  registrar cambio técnico;
2.  informar impacto académico;
3.  actualizar `docs/INTEGRATION.md`;
4.  identificar capturas/tablas/resultados que podrían quedar obsoletos;
5.  actualizar el Word solo después de validar el software.

## Regla de fuente de verdad

El compañero no debe describir como implementada una funcionalidad que
todavía no exista en el código.

Claude no debe inventar resultados académicos que no estén respaldados
por pruebas o por la fuente correspondiente.
