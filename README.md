# Room Acoustic

Software para evaluación acústica de aulas, desarrollado como proyecto
de grado de Ingeniería Industrial de la Universidad del Atlántico.

## Funciones principales

- Tiempo de Reverberación.
- Sabine.
- Eyring.
- Inteligibilidad del Habla.
- %ALCons mediante modelo de Peutz.
- Base de datos de 23 tipos de salón del Bloque H.
- Visualización de resultados.
- Generación de reportes PDF.

## Tecnología

- Python
- PySide6 / Qt6
- Qt Designer
- pandas
- Matplotlib
- ReportLab
